# Definition of Done — Metropolis van de Toekomst

Een User Story is "Done" wanneer aan ALLE onderstaande criteria is voldaan.

## Code

- [ ] De code staat in de juiste branch op GitHub en is gemerged naar `main`
- [ ] De code volgt de afgesproken naming conventions (camelCase voor variabelen, PascalCase voor classes)
- [ ] De code is leesbaar en voorzien van commentaar waar nodiggggg
- [ ] Er staan geen `dd()`, `var_dump()` of andere debug statements in de code
- [ ] De code is geen kopie, maar zelf geschreven

## Functionaliteit

- [ ] Alle acceptatiecriteria uit de User Story zijn afgewerkt
- [ ] De functionaliteit werkt in de laatste versie van Chrome en Firefox
- [ ] De functionaliteit werkt op zowel desktop als mobiel (320px+)
- [ ] Data wordt correct opgeslagen en opgehaald uit de MySQL database
- [ ] Er zijn geen errors zichtbaar in de browser console of Laravel log

## Testen

- [ ] De User Story is handmatig getest door de uitvoerder
- [ ] De User Story is peer-reviewed door een ander teamlid
- [ ] Edge cases zijn getest (lege invoer, ongeldige invoer, refresh van pagina)
- [ ] De functionaliteit is getest op een lege database én een gevulde database

## Documentatie

- [ ] Wijzigingen zijn gedocumenteerd in de README indien relevant
- [ ] De bijbehorende subtask in Jira is op "Done" gezet
- [ ] Tijdregistratie is bijgewerkt in Jira

## Oplevering

- [ ] De User Story is gedemonstreerd tijdens de sprint review
- [ ] De Product Owner heeft de User Story geaccepteerd
- [ ] Alle gemaakte code is up-to-date gepusht naar GitHub
